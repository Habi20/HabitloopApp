
# NotUsed Directory

This directory contains archived and experimental files that are not part of the core application:

## Structure

- **documentation/** - Development documentation, guides, and reports
- **testing/** - Test files, configurations, and experimental test setups
- **ml-experiments/** - Machine learning prototypes and experimental models
- **assets/** - Attached assets, screenshots, and development artifacts
- **config-old/** - Legacy configuration files and alternative auth setups

## Purpose

These files have been moved here to:
- Clean up the main project structure
- Preserve development history and documentation
- Keep experimental features for potential future use
- Maintain a cleaner development environment

## Note

Files in this directory are not part of the production application and may contain outdated or experimental code.
